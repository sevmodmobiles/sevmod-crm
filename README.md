# SEVMOD CRM — демонстрационный интерфейс

Статический прототип рабочего стола SEVMOD CRM, готовый к публикации через GitHub Pages.

## Публикация

1. Создайте репозиторий `sevmod-crm` на GitHub.
2. Загрузите `index.html` в корень ветки `main`.
3. В Settings → Pages → Build and deployment выберите **Deploy from a branch**, ветку **main**, папку **/(root)**, затем Save.
4. Откройте `https://<ваш-логин>.github.io/sevmod-crm/` после завершения публикации.

Для обновления страницы достаточно заменить `index.html` в репозитории. GitHub Pages публикует изменения автоматически после коммита.

## Важно

- Данные демонстрационные, новые сделки и задачи сохраняются в `localStorage` конкретного браузера, не синхронизируются между пользователями.
- Не загружайте реальные клиентские или коммерческие данные в публичный демо-сайт.
- Для рабочей CRM нужны сервер, база данных, авторизация и контроль доступа.
